# Archivos temporales

Resultados de comprobaciones, SQLite de pruebas y cachés trasladadas durante la organización. No contiene la base real de `data/` ni código de aplicación.

Las carpetas `pytest-*` se crean con pruebas que usan `--basetemp`; `cache/` agrupa cachés antiguas. Son regenerables y no se versionan. No necesitas modificarlas para desarrollar. Algunas carpetas creadas por otras ejecuciones pueden tener permisos restringidos.
